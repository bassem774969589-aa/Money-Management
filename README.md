# Money-Management
MaliTrack — متابعتي المالية 💰

MaliTrack هو تطبيق ويب عربي حديث وبسيط يساعد المستخدم على إدارة راتبه ومتابعة مصروفاته والتزاماته المالية في مكان واحد.

يتيح التطبيق تسجيل الراتب الشهري، وإدارة المصروفات الأساسية، والديون الحالية، والأقساط التي يتم خصمها من الراتب، بالإضافة إلى متابعة الديون السابقة وتسجيل دفعات السداد حتى اكتمالها.

✨ أهم المميزات

- 💵 إدارة الراتب الشهري.
- 🛒 تسجيل وإدارة المصروفات الأساسية.
- 💳 إدارة الديون الحالية والأقساط الشهرية.
- 📄 إدارة الأقساط التي تُخصم تلقائيًا من الراتب.
- 🔄 احتساب الخصم الشهري للأقساط تلقائيًا.
- 📅 تحديد تاريخ بداية القسط وعدد الأقساط.
- ⏳ متابعة الديون السابقة غير المسددة.
- 💰 تسجيل دفعات سداد الديون.
- 📊 شريط تقدم يوضح نسبة سداد كل دين.
- 📦 أرشفة الديون عند اكتمال سدادها تلقائيًا.
- 📈 لوحة إحصائيات مالية مباشرة.
- 🧮 حساب الصافي الفعلي بعد جميع الالتزامات.
- 🔐 حفظ البيانات محليًا باستخدام "LocalStorage".
- 📱 تصميم متجاوب يعمل على الهاتف والكمبيوتر.
- 🌐 واجهة عربية بالكامل باتجاه RTL.
- 🛡️ حماية من إدخال HTML غير آمن.
- ⚡ يعمل مباشرة من ملف "index.html" بدون خادم أو قاعدة بيانات.

🧮 طريقة احتساب الصافي

يحسب التطبيق الصافي الفعلي وفق المعادلة:

الصافي = الراتب − المصروفات الأساسية − الديون الحالية − أقساط الراتب − سداد الديون السابقة خلال الشهر الحالي

وبذلك يعطي المستخدم صورة أوضح عن المبلغ المتبقي فعليًا بعد الالتزامات الشهرية.

🛠️ التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript Vanilla
- Tailwind CSS
- Font Awesome
- Google Fonts — Cairo
- LocalStorage API

🚀 التشغيل

لا يحتاج المشروع إلى تثبيت أو إعداد خادم.

يمكن تشغيله مباشرة بفتح:

"index.html"

في أي متصفح حديث.

🎯 هدف المشروع

تم تطوير MaliTrack لتوفير أداة مالية شخصية خفيفة وسهلة الاستخدام، تساعد المستخدم على معرفة أين يذهب راتبه، وما هي التزاماته الشهرية، وكم يتبقى له فعليًا بعد الخصومات.
